Декомпозиция эпика «Профиль»

Задача 1. Реализовать основной экран профиля и редактирование данных пользователя
1. Реализовать получение данных профиля пользователя из мокового API: имя, описание, сайт и аватар - 3 ч
2. Подготовить экранную логику профиля и редактирования: загрузка, успешное состояние, ошибка и сохранение изменений - 4 ч
3. Сверстать основной экран профиля: аватар, имя пользователя, описание, сайт, кнопку редактирования и блоки «Мои NFT» / «Избранные NFT» - 6 ч
4. Реализовать получение и отображение количества NFT пользователя и избранных NFT из мокового API - 3 ч
5. Реализовать переход на экран редактирования профиля - 1 ч
6. Сверстать экран редактирования профиля с полями «Имя», «Описание», «Сайт», аватаром и кнопкой «Сохранить» - 5 ч
7. Реализовать заполнение полей текущими данными профиля и редактирование данных пользователя - 3 ч
8. Реализовать изменение и удаление фотографии профиля - 3 ч
9. Реализовать сохранение измененных данных профиля в моковом API и обновление основного экрана - 4 ч
10. Реализовать обработку ошибок и подтверждение выхода при наличии несохраненных изменений - 3 ч
11. Подключить экран профиля как вкладку в общем таббаре приложения - 1 ч
Итого: 36 ч

Задача 2. Реализовать экран «Мои NFT» и сортировку NFT
1. Реализовать переход с основного экрана профиля на экран «Мои NFT» - 1 ч
2. Реализовать получение списка NFT пользователя из мокового API - 3 ч
3. Реализовать получение данных NFT из мокового API: изображение, название, рейтинг, автор и цена - 4 ч
4. Подготовить экранную логику «Мои NFT»: состояние загрузки, состояние списка NFT и состояние пустого списка - 3 ч
5. Сверстать навигационную панель экрана «Мои NFT» с кнопкой назад и кнопкой сортировки - 2 ч
6. Сверстать ячейку NFT: изображение, название, рейтинг, автор и цена - 4 ч
7. Сверстать список NFT пользователя на основе загруженных моковых данных - 2 ч
8. Сверстать пустое состояние «У Вас ещё нет NFT» - 2 ч
9. Реализовать обновление списка NFT при повторном открытии экрана с учетом данных из мокового API - 2 ч
10. Сверстать и подключить окно выбора сортировки с вариантами «По цене», «По рейтингу», «По названию» и «Закрыть» - 3 ч
11. Реализовать открытие окна сортировки по кнопке в навигационной панели - 1 ч
12. Добавить логику сортировки NFT по цене, рейтингу и названию на основе полученных моковых данных - 4 ч
13. Сохранять выбранный способ сортировки в состоянии экрана - 2 ч
14. Обновлять список NFT после выбора способа сортировки - 2 ч
15. Обрабатывать пустой список NFT без открытия сортировки или без изменения состояния - 1 ч
Итого: 36 ч

Задача 3. Реализовать экран «Избранные NFT»
1. Реализовать переход с основного экрана профиля на экран «Избранные NFT» - 1 ч
2. Реализовать получение списка избранных NFT из мокового API - 3 ч
3. Реализовать получение данных избранных NFT из мокового API: изображение, название, рейтинг и цена - 4 ч
4. Подготовить экранную логику избранного: состояние загрузки, состояние списка избранных NFT и состояние пустого списка - 3 ч
5. Сверстать навигационную панель экрана «Избранные NFT» с кнопкой назад - 1.5 ч
6. Сверстать ячейку избранного NFT: изображение, название, рейтинг, цена и индикатор избранного - 4 ч
7. Сверстать сетку избранных NFT в две колонки - 3 ч
8. Сверстать пустое состояние «У Вас ещё нет избранных NFT» - 2 ч
9. Реализовать удаление NFT из избранного в моковом API по нажатию на иконку сердечка - 3 ч
10. Обновлять список и счетчик избранных NFT после удаления из избранного - 2 ч
Итого: 26.5 ч

Общий итог по эпику «Профиль»: 98.5 ч
