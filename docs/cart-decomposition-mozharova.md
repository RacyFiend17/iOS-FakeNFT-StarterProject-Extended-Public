# Декомпозиция эпика «Корзина»

## Задача 1. Реализовать основной экран корзины

1. Реализовать получение текущего заказа с сервера, чтобы узнать, какие NFT находятся в корзине - **3 ч**, факт: **2 ч**
2. Реализовать получение данных NFT по id из заказа: изображение, название, рейтинг и цена - **4 ч**, факт: **1 ч**
3. Подготовить экранную логику корзины: состояние загрузки, состояние пустой корзины, состояние корзины со списком NFT - **3 ч**, факт: **1 ч**
4. Подготовить расчет итоговых данных корзины: количество NFT и общая стоимость в ETH - **2 ч**, факт: **0.5 ч**
5. Сверстать ячейку NFT в корзине: изображение, название, рейтинг, цена и кнопка удаления без рабочей логики удаления - **3 ч**, факт: **3 ч**
6. Сверстать список NFT на экране корзины на основе загруженных данных - **2 ч**, факт: **0.5 ч**
7. Сверстать нижний блок корзины: количество NFT, итоговая стоимость и кнопка «К оплате» - **3 ч**, факт: **1 ч**
8. Сверстать кнопку сортировки на основном экране без рабочей логики сортировки - **1 ч**, факт: **0.5 ч**
9. Сверстать пустое состояние корзины - **2 ч**, факт: **0.5 ч**
10. Собрать основной экран корзины из списка, кнопки сортировки, нижнего блока оплаты и пустого состояния + реализовать обработку ошибок - **3 ч**, факт: **4 ч**
11. Подключить экран корзины как вкладку в общем таббаре - **1 ч**, факт: **1 ч**
12. Настроить обновление корзины при повторном открытии экрана, чтобы отображать NFT, добавленные из каталога - **2 ч**, факт: **1 ч**

Итого: **29 ч**
Итого факт: **16 ч**

## Задача 2. Реализовать экран выбора способа оплаты и переход к нему

1. Реализовать получение списка валют с сервера - **3 ч**
2. Подготовить экранную логику выбора оплаты: состояние загрузки валют, состояние списка валют, выбранная валюта - **3 ч**
3. Сверстать ячейку валюты: иконка, название и сокращение - **3 ч**
4. Сверстать список валют на экране выбора способа оплаты - **2 ч**
5. Реализовать выбор валюты пользователем вместе с визуальным состоянием выбранной валюты - **2.5 ч**
6. Сохранять выбранную валюту в состоянии экрана и использовать ее для управления доступностью кнопки «Оплатить» - **2 ч**
7. Сверстать нижнюю часть экрана оплаты: текст про пользовательское соглашение и кнопку «Оплатить» - **2.5 ч**
8. Реализовать переход с экрана корзины на экран выбора способа оплаты по кнопке «К оплате» - **2 ч**
9. Реализовать открытие пользовательского соглашения в web view - **4 ч**

Итого: **24 ч**

## Задача 3. Реализовать сортировку, удаление и оплату заказа

1. Добавить логику сортировки NFT в корзине по цене, рейтингу и названию, а также сохранение выбранного способа сортировки - **4 ч**
2. Сверстать и подключить окно выбора сортировки к экрану корзины - **2 ч**
3. Добавить логику выбора NFT для удаления и удаления выбранного NFT из заказа на сервере - **3 ч**
4. Сверстать и подключить окно подтверждения удаления NFT с изображением выбранного NFT, текстом подтверждения и кнопками отмены/удаления - **3 ч**
5. Обновлять экран корзины после удаления NFT: список товаров, количество NFT, итоговую стоимость и состояние пустой корзины - **3 ч**
6. Добавить логику оплаты заказа выбранной валютой - **3 ч**
7. После успешной оплаты выполнить завершение заказа на сервере, чтобы купленные NFT были доступны в разделе «Мои NFT» - **3 ч**
8. Сверстать экран успешной оплаты и настроить переход на него после успешного ответа сервера - **3 ч**
9. Реализовать возврат с экрана успешной оплаты обратно в корзину по кнопке «Вернуться в корзину» - **1 ч**
10. Сверстать и подключить окно ошибки оплаты с действиями «Отмена» и «Повторить» - **2 ч**
11. Реализовать повторную попытку оплаты после ошибки - **2 ч**
12. Обновлять состояние корзины после завершения оплаты и отображать актуальные данные заказа с сервера - **2 ч**

Итого: **31 ч**
